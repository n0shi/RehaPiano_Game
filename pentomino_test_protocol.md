# Pentomino (RehaPiano glove) — Prototype Test Protocol

Goal: find problems with the glove controls and the game itself before the prototype release. One session takes about 20 minutes.

## Part A — For the test leader

**Before the session:** glove charged and connected (status “connected”), game opened fresh (Ctrl+F5), finger and position calibration done with the tester. Write down the hand used and the glove position (normal / rotated “holding a glass”).

**Tasks** (explain once, then do not help unless the tester is stuck for more than 1 minute):

1. Move the cursor to each corner of the board and back to the centre.
2. Grab a piece (squeeze all 5 fingers), move it left, right, up and down, then release it.
3. Rotate a piece (turn the wrist) and flip it (tilt the wrist towards / away from you).
4. Place a piece next to another piece and next to the board edge.
5. Reset the cursor position (hold all fingers squeezed for 3 s without moving).
6. Solve the first level (max. 10 minutes).

**Problem log** — tick each time it happens and add a short note (task number, what the tester did):

| Problem | Count | Note |
|---|---|---|
| Cursor jumps / flies away after releasing a piece | | |
| Cursor sticks to cells or moves in steps | | |
